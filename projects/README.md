# Project-scoped memory

Each subfolder here is named after a project slug (e.g. `llm-wiki`, `ipfabric-product`) and holds memory files scoped to that project only — `user`-type memories never belong here, only `feedback`, `project`, and `reference`.

Create a new `<slug>/` folder the first time memory-worthy context appears for a project that doesn't have one yet. See the root [CLAUDE.md](../CLAUDE.md) for the full schema and file format.
