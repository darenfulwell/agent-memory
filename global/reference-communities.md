**Network Automation Forum (NAF) Slack:** `networkautomationfrm.slack.com`
Co-founded by Scott Robohn and Chris Grundemann (see llm-wiki people pages if they exist). Many practitioners in Daren's network are active here — John Howard, Scott Robohn, Chris Grundemann, and others in the network automation space. Note: the Slack MCP tools available by default are connected to IP Fabric's workspace, not NAF — NAF Slack can only be accessed manually.

**AutoCon conference series:** organised by NAF. AutoCon 5 = Munich 2026. Next events tracked at networkautomationfrm.org.

**Network to Code Slack:** `networktocode.slack.com` — founded by Jason Edelman alongside the Network to Code company. One of the largest and most active network automation practitioner communities. John Capobianco and many other community figures are active here.

**VibeOps Forum Slack:** `vibeopsforum.slack.com` — community Slack for VibeOps / AI-in-ops practitioners.

**Packet Pushers:** podcast network hosting TNOps (Scott Robohn) and other shows featuring community members. packetpushers.net.

**Slack MCP access note:** the org-managed Slack MCP connects to the IP Fabric workspace only. To access NAF/NTC/VibeOps Slacks, either ask the Claude admin to add them in the Enterprise portal, or configure local MCP server entries using user tokens for each workspace.
